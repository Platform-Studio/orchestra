# Support

## Questions And Ideas

Use [GitHub Discussions](https://github.com/Platform-Studio/orchestra/discussions) for setup questions, usage help, and early feature ideas. Search existing discussions and documentation first.

Community support is best-effort. Platform Studio does not guarantee response or resolution times for general support requests.

## Bugs

Use a [GitHub issue](https://github.com/Platform-Studio/orchestra/issues) for reproducible bugs. Include the Orchestra version, operating system, Python version, relevant configuration with secrets removed, reproduction steps, expected behavior, and actual behavior.

Use the issue tracker for actionable work rather than general troubleshooting or private operational data.

## Security

Follow `SECURITY.md` for suspected vulnerabilities. Never post vulnerabilities, credentials, private prompts, or user data in a public issue or discussion.

## Commercial Support

This repository does not currently include a commercial support commitment. Any future hosted or commercial offering will document its support terms separately from community support for the open-source project.
